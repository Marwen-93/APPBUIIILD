How to run:
1. Install Android Studio (free).
2. File > Open > select the ArabicMathApp folder, wait for Gradle sync.
3. Press Run (green triangle) on an emulator or a USB-connected phone.
4. To get an APK: Build > Build Bundle(s)/APK(s) > Build APK(s).

No Android Studio? Build the APK on GitHub:
1. Create a free GitHub account and a new repository.
2. Upload ALL files of this folder (including the hidden .github folder).
3. Open the Actions tab, wait for "Build APK" to finish (3-5 min).
4. Open the finished run and download the "ArabicMath-APK" artifact (a zip containing app-debug.apk).
